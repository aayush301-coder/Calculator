# 📱 Modern Calculator

A sleek, responsive calculator built using pure **HTML, CSS, and JavaScript**. Designed with modern UI principles, keyboard support, and smooth interaction feedback.

---

## 🚀 Features

* Responsive modern design
* Keyboard input support
* Error handling for invalid expressions
* Delete last digit function
* Color-coded operators for clarity
* Smooth hover and click animations
* Safe evaluation handling
* Mobile-friendly layout

---

## 🧠 Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling & Layout
* **JavaScript** — Logic & Interaction

---

## 🎮 Controls

| Key       | Action            |
| --------- | ----------------- |
| Numbers   | Input values      |
| Operators | + − × ÷           |
| Enter     | Calculate         |
| Backspace | Delete last digit |
| Esc       | Clear display     |
